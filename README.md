# Our Slice — Update 6
Replace only the repository root `index.html` with this file.

Added a scrollable Busselton foreshore, a long jetty scaled to represent 1,841 metres, fishing interactions, a simplified train-ride interaction, and a first-look underwater observatory interaction. Tegan, Kieran and Aggie appear together. Use Travel to visit Busselton foreshore from the Goose Café or bush block.

This remains a single-device prototype, not online multiplayer. The twice-daily train is represented by two selectable departures, not a running in-game clock. Fishing is a simple random-catch interaction, not a full minigame. The observatory is an interaction, not yet a walkable interior. Character art remains temporary.

Bush save key `our-slice-bush-v2` and café save key `our-slice-cafe-v1` remain unchanged. Foreshore progress is stored separately under `our-slice-foreshore-v1`.
